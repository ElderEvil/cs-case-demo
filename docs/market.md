# Market snapshot (2026-09-03)

Based on internal research notes.

## How it works

Steam login → top-up (card/crypto/skins) → open custom cases → withdraw to
Steam / sell / Battles / Upgrader / Contracts. Leaders publish full odds +
Provably Fair (`SHA256(server_seed)` upfront, `HMAC(server_seed, client:nonce)`
per roll). Valve drops lock value in Steam Wallet (15% fee, non-withdrawable) —
third-party sites sell faster exit (<60s–15m Steam trade, P2P, crypto).

400M cases/yr. UA: top-5 CS nation (NAVI/s1mple), Hr 17.2B gambling tax 2024,
4,500 illegal casinos shut. RTP 83–97% (house edge 3–15% minus 10–20% promo CAC).
